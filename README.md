# PhysioMotion · Prototipo web

Prototipo funcional de **PhysioMotion**, una plataforma de ejercicios de fisioterapia guiados para adultos mayores, con meditación y seguimiento de progreso.

**Demo en vivo:** `https://TU-USUARIO.github.io/physiomotion/`

## Pantallas

1. **Bienvenida:** ingreso con apodo.
2. **Cuestionario:** 5 preguntas, una por pantalla, con barra de progreso.
3. **Inicio:** plan personalizado con 3 niveles que se desbloquean en orden.
4. **Ejercicio:** contador guiado de repeticiones con pausa y opción de saltar.
5. **Nivel completado:** celebración y suma de XP.
6. **Perfil:** apodo editable, XP, niveles, meta diaria y datos del usuario.
7. **Meditación:** respiración guiada 4-7-8 y escaneo corporal.
8. **Progreso:** días de ejercicio y calendario mensual.

Incluye botón de texto grande y lectura en voz alta. Los datos se guardan solo en el navegador.

## Tecnologías

HTML, CSS y JavaScript puro, en un único archivo `index.html` (las imágenes van incrustadas).

## Publicar en GitHub Pages

1. Crea un repositorio público, por ejemplo `physiomotion`.
2. **Add file → Upload files** → sube `index.html` (y este `README.md`) → **Commit changes**.
3. **Settings → Pages** → Source: **Deploy from a branch** → rama **main**, carpeta **/ (root)** → **Save**.
4. Espera 1–2 minutos: el enlace aparece en la parte superior de esa misma página.
